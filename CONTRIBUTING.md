# Contributing

Task-source requests and pull requests are welcome. For a new adapter, describe how it observes task state, add synthetic tests for startup, completion, approval and unreadable state, and follow the [task-source protocol](TASK_SOURCES.md). See the [build instructions](README.md#build-and-contribute) for local verification.

Use `git commit -s` to sign off each commit under the [Developer Certificate of Origin 1.1](https://developercertificate.org/). Set a GitHub-provided noreply address if you want to keep your email private. DCO sign-off is the textual `Signed-off-by` trailer. Authenticode signing of Windows binaries is separate.
